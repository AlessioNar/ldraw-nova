# Querying the ontology

The ontology is published as Turtle under `https://alessionar.github.io/open-brick-designer/ns/` (files in [`docs/ns/`](../ns/)):
`obd.ttl` (components and parameters), `roles.ttl` (roles), `shapes.ttl` (validity rules), `vehicles.ttl` (vehicles and spaceships), `sets.ttl` (sets and brands), `furniture.ttl` (furniture kinds found in the reference sets and the furniture designs) and `ontology.ttl` (all of them).
Licence CC BY-SA 4.0. The sources are `ontology/*.ttl`; `docs/ns/` is generated by `python tools/export_ontology.py`
and CI fails when it is out of date. Design: [`docs/plans/active/build-ontology/PROPOSAL.md`](../plans/active/build-ontology/PROPOSAL.md).

Load it with rdflib (`pip install rdflib`), or any SPARQL engine that reads Turtle:

```python
from rdflib import Graph
g = Graph().parse('docs/ns/ontology.ttl')          # or the https URL above
for row in g.query(QUERY, initNs={...}):            # QUERY is one of the queries below
    print(*row)
```

Every query below runs against `ontology.ttl` with these prefixes (they are declared in the file, so rdflib needs no `initNs`):

```sparql
PREFIX obd: <https://alessionar.github.io/open-brick-designer/ns/obd#>
PREFIX role: <https://alessionar.github.io/open-brick-designer/ns/role/>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
PREFIX owl: <http://www.w3.org/2002/07/owl#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX dcterms: <http://purl.org/dc/terms/>
PREFIX sh: <http://www.w3.org/ns/shacl#>
PREFIX brand: <https://alessionar.github.io/open-brick-designer/ns/brand/>
```

`tests/test_ontology_export.py` runs each query and checks it returns rows, so the cookbook cannot rot.

## Roles

### List the roles, in display order

```sparql
# cookbook: roles
SELECT ?role ?definition WHERE {
  ?role a skos:Concept ; obd:order ?n ; skos:definition ?definition .
} ORDER BY ?n
```

### Which role does a word mean?

```sparql
# cookbook: word-to-role
SELECT ?role WHERE {
  ?role a skos:Concept ; skos:altLabel ?w .
  FILTER (lcase(str(?w)) = "masonry")
}
```

### Roles that fold into another role

```sparql
# cookbook: role-aliases
SELECT ?role ?broader WHERE { ?role skos:broader ?broader } ORDER BY ?role
```

## Components and parameters

### Component kinds and what each places

```sparql
# cookbook: component-roles
SELECT ?component ?role WHERE {
  ?component rdfs:subClassOf obd:Component ; obd:role ?role .
} ORDER BY ?component ?role
```

### Every parameter of a component with its default

```sparql
# cookbook: roof-parameters
SELECT ?key ?default ?comment WHERE {
  ?p a obd:Parameter ; rdfs:domain obd:Roof ; dcterms:identifier ?key ; obd:order ?n .
  OPTIONAL { ?p obd:default ?default }
  OPTIONAL { ?p rdfs:comment ?comment }
} ORDER BY ?n
```

### The colour parameters

```sparql
# cookbook: colour-parameters
SELECT ?p ?key WHERE { ?p a obd:ColourParameter ; dcterms:identifier ?key } ORDER BY ?p
```

## Validity rules

### List the rules and their messages

```sparql
# cookbook: rules
SELECT ?rule ?message WHERE {
  ?shape dcterms:identifier ?rule .
  { ?shape sh:sparql/sh:message ?message } UNION { ?shape sh:property/sh:message ?message }
} ORDER BY ?rule
```

## Brands

### List the brands with their alternative spellings

```sparql
# cookbook: brands
SELECT ?brand (GROUP_CONCAT(?alt; separator=", ") AS ?spellings) WHERE {
  ?b skos:inScheme brand: ; skos:prefLabel ?brand ; skos:altLabel ?alt .
} GROUP BY ?brand
```

Sets are brand-agnostic: an `obd:Set` points at a brand concept with `obd:brand`, lists its parts with `obd:contains` (`obd:part`, `obd:colour`,
`obd:quantity`) and names where the list came from with `obd:partsSource`. A new brand is a new `skos:Concept` in `ontology/sets.ttl`.
`ontology/sets-shapes.ttl` is the SHACL shape (a brand, a name, positive quantities); `tests/fixtures/sets-sample.ttl` holds a LEGO and a CADA sample.
Owned sets stay in the app database, not in RDF.

## Validating a build

Rules are SHACL, so validating a config takes `pyshacl` (toolkit-only; the app uses `normalise()` at runtime):

```
pip install rdflib pyshacl
python tools/validate_shapes.py --presets
python tools/validate_shapes.py config.json
```

Furniture (`furniture.ttl`): each kind in the `furn:` scheme carries how many pieces and sets it was found in (`obd:referencePieces`, `obd:referenceSets`), its typical size and the parts it uses most (`obd:vocabulary`); each design (`build:chair`, `build:dining-table`...) names the kinds it follows (`obd:drawnFrom`) and its default footprint (`obd:furnitureWidth`, `obd:furnitureDepth`, `obd:furnitureHeight`). The catalogue is regenerated with `python tools/harvest_furniture.py`; `tests/test_furniture.py` keeps the file, the JSON catalogue and the generators in step.
