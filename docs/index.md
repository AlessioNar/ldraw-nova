# Open Brick Designer

Open Brick Designer is a desktop web app for designing LEGO-compatible models as [LDraw](https://www.ldraw.org/) files. You start a build, describe it or place parts in a 3D workspace, and rule-based generators do most of the work; an AI agent runs only when you agree to its price. Your own parts and sets can steer what gets built.

This site is its documentation.
